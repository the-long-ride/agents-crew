# Built-in Agent Roles

## Mission

This folder contains the default instructions installed for each crew role.

## Roles

- `manager.md` plans, delegates, reviews, and follows Rust-issued actions.
- `planner.md` creates bounded task graphs and acceptance criteria.
- `researcher.md` performs read-only repository investigation.
- `implementer.md` makes scoped code changes.
- `tester.md` executes and reports verification.
- `reviewer.md` performs independent evidence-based review.
- `integrator.md` resolves bounded integration work.

## Editing rules

Role prompts cannot grant capabilities. The Rust policy engine, task envelope, and host sandbox remain authoritative.
