# Project Documentation

## Mission

This folder explains installation, configuration, security, manager protocol, release operations, troubleshooting, and approved engineering decisions.

## Files

- `installation.md` covers binary and installer setup.
- `configuration.md` documents `crew.toml` and routing behavior.
- `manager-protocol.md` defines manager action exchange.
- `security.md` describes trust boundaries and approvals.
- `troubleshooting.md` maps common states to fixes.
- `releasing.md` documents GitHub Release and npm publication.
- `superpowers/` stores reviewed design specifications and implementation plans.

## Editing rules

Documentation must describe enforced behavior, not aspirational behavior. Link commands to the exact source or workflow that implements them.
